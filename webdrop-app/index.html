Setup guide

Build apps with your own GitHub, step by step.

Do you need this?

Probably not. If you sign in with Google, Quick Build makes your apps for you with no setup. This guide is only for building with your own GitHub (free and unlimited). It takes about 5 minutes, once.

Build with your own GitHub

  1. Make a GitHub account

    Skip this if you already have one.

    Open github.com/signup

  2. Create an empty repository

    1. Open github.com/new
    2. Repository name: webdrop-builds
    3. Choose Public (public repos build for free)
    4. Tap Create repository

  3. Upload the build kit

    1. Download the kit: ⇩ Build kit (.zip)
    2. Unzip it. Inside are two folders: .github and android
    3. In your new repo tap uploading an existing file, drag in both folders, then tap Commit changes

    💡 The .github folder can be hidden on your computer. Mac: press Cmd ⌘ + Shift + . · Windows: View→Show hidden items. A computer is easier than a phone for this step.

    ✓ Check: your repo now shows the folders .github and android

  4. Create a token (a password for WebDrop)

    1. Open github.com/settings/tokens/new
    2. Note: WebDrop · Expiration: No expiration
    3. Tick ☑ repo and ☑ workflow. Nothing else is needed
    4. Tap Generate token and copy it (it starts with ghp_)

    GitHub only shows it once, so paste it in the next step straight away.

  5. Connect WebDrop

    1. Go to →Build service
    2. Repository: yourname/webdrop-builds (your GitHub name / repo name)
    3. Token: paste it, then tap Save & test
    ✓ Check: it says “Connected ✓ … build workflow found”

  6. Build an app

    1. On , enter a website and tap Prepare APK build
    2. Watch it in . It takes about 5 minutes
    3. Tap ⇩ Download APK and install it

If something goes wrong

“GitHub rejected that token”
Make a new token and make sure both repo and workflow are ticked.
“build-apk.yml isn’t in it yet”
The .github folder didn’t upload (it’s often hidden). Show hidden files and upload it again.
“The build failed”
Tap View run on the build to see which step broke.
Android won’t install it
Allow installs from your browser or Files app when Android asks, and uninstall any older copy first.

Good to know

  1. Website icons are automatic. The build downloads your site’s own icon (apple-touch-icon, favicon) and falls back to a clean default.
  2. Keeping updates installable: add secrets KEYSTORE_BASE64, KEYSTORE_PASSWORD and KEY_ALIAS to the repo. Without them each build uses a one-off key and must be uninstalled before reinstalling.
  3. Only https:// sites work — Android blocks plain http.
